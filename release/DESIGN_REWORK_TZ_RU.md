# ТЗ на редизайн MSLaunch

Цель: уйти от старого формата лаунчера с мусорной информацией, рекламными блоками и неудобными кнопками. Новый MSLaunch должен выглядеть как современный мягкий киношный Minecraft launcher, который понятен ребенку 5-7 лет и при этом не выглядит дешево для команды съемок.

## Главная идея

Один лаунчер, несколько клиентских режимов:

- `MSLaunch`: независимый режим по умолчанию для обычных игроков.
- `MS Nuckem`: режим заказчика/команды Нюкема, с паролем на скачивание модов.
- `VibeCraft`: будущий режим личного сервера.

Логика запуска и синхронизации одна. Меняются только бренд, фон, ссылки, тексты, доступные кнопки и preset конфига.

## Одобренные бренды

- `MSLaunch`: основной логотип с кубом `MS`.
- `MS Nuckem`: круглая иконка `KH`, подпись `MS Nuckem`, verified check.
- `VibeCraft`: золотой/бирюзовый fantasy logo.

В UI нельзя использовать буквенные заглушки вместо одобренных иконок, кроме временного fallback для отсутствующего asset.

## Поведение режимов

### Independent / MSLaunch

- Первый запуск открывается в нейтральном MSLaunch.
- Никаких упоминаний Нюкема.
- Показываются только базовые кнопки: настройки, отчеты/помощь, режимы.
- Игрок может выбрать версию, сборку, ник, проверить моды или играть.

### MS Nuckem

- Активируется через переключатель режима.
- Показывает логотип `MS Nuckem`.
- Показывает только ссылки заказчика.
- Кнопка `Download Mods` и запуск через серверный профиль требуют пароль, если включен `password_enabled`.
- Если пароль неверный: показать понятную ошибку:
  `Вы не знаете актуальный пароль. Уточните детали у администрации Нюкема.`
- Если hash пароля не настроен: запуск/скачивание блокируется, админ должен заполнить `password_hash_sha256`.

### VibeCraft

- Временно можно сделать сыро, но режим должен переключаться и показывать логотип/фон VibeCraft.
- Логика такая же: build/source_key/manifest берутся из config.
- Не мешать с режимом Нюкема.

## Новый UI

Запрещено:

- рекламная лента как у TLauncher;
- новостная помойка;
- огромные бесполезные блоки;
- кислотный салатовый цвет;
- устаревшие глянцевые кнопки 2010 года;
- мелкий непонятный текст;
- кнопки без очевидной пользы.

Обязательные зоны:

- верх/лево: логотип активного режима;
- переключатель режимов: `MSLaunch / MS Nuckem / VibeCraft`;
- центральный статус: что происходит сейчас;
- нижняя панель: ник, сборка, версия, язык, `Download Mods`, `Play`;
- помощь/отчеты: понятное объяснение ошибок, кнопка открыть отчеты.

## Статусная панель

Вместо мусорных новостей показывать полезные состояния:

- `Mods ready`;
- `Downloading mods`;
- `Fabric OK`;
- `Fabric API missing`;
- `Java OK`;
- `Java too old`;
- `Crash report found`;
- `Wrong password`;
- `Server config missing`.

Главная задача: игрок понимает, что нажать и что сломалось.

## Фон и визуальный стиль

Ориентир: мягкий киношный Minecraft, vanilla, без детского сада.

Фон должен быть отдельным слоем от UI:

- 5 фоновых картинок;
- parallax по курсору;
- частицы/пыль очень мягкие;
- glass panels поверх фона;
- без сильной дымки и грязных прямоугольников.

## Два варианта лаунчера

### Вариант A: Living Poster Command Dock

Лучший для первого впечатления.

- Фон почти как живой постер.
- Главные действия в нижнем dock.
- Справа крупные статусы `Mods/Fabric/Java`.
- Меньше текста, больше ощущения premium launcher.

### Вариант B: Clean Command Deck

Лучший для команды Нюкема и техподдержки.

- Больше статусов и объяснений.
- Слева список проектов/режимов.
- Справа панель `What happens now`.
- Очень понятно, что делать дальше.

## Рекомендация

Для реализации брать гибрид:

- база: `Variant A`;
- логика статусов/помощи: из `Variant B`;
- фон: мягкий vanilla/cinematic;
- режим Нюкема: использовать `MS Nuckem` logo и ссылки заказчика;
- VibeCraft: добавить как третий preset, даже если дизайн пока черновой.

## Критерий готовности редизайна

- ребенок понимает: где ник, где моды, где играть;
- админ понимает: где отчеты, где ошибка, где source config;
- заказчик видит свой бренд без ощущения старого лаунчера;
- independent mode не выглядит как чужой клиентский лаунчер;
- никаких пустых кнопок и лишней информации.
