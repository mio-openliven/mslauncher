MSLaunch: инструкция для игрока

1. Откройте папку с лаунчером.
2. Запустите MSLauncher.exe.
3. Введите никнейм.
4. Выберите сборку и профиль, если это нужно.
5. Нажмите "Играть".
6. Если нужно только проверить файлы без запуска игры, нажмите "Моды".
7. Дождитесь проверки и скачивания файлов.

Если появилась ошибка:

1. Нажмите кнопку открытия отчетов/логов в лаунчере.
2. Отправьте администратору файл mslauncher-last-error.txt.
3. Если Minecraft вылетел, отправьте latest.log или файл из crash-reports.

Java автоматически не устанавливается. Если лаунчер пишет про Java, установите нужную Java или попросите администратора подсказать путь к java.exe.
