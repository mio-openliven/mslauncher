# MSLaunch User Routing Flow

Короткое правило: не думай после отчета агента. Смотри `NEXT ROUTE`.

## Автокруг через Штурмана

Если болеешь или не хочешь бегать по чатам, напиши Штурману:

```text
Автокруг 15. Стартуй с текущего NEXT ROUTE.
```

Что делает Штурман:

- читает последний отчет агента;
- отправляет prompt нужному агенту;
- выбирает модель по `NEXT ROUTE`;
- повторяет до 15 ходов;
- останавливается, если нужен человек.

Штурман остановится, если:

- нет `NEXT ROUTE`;
- агент сломал роль;
- проверки упали;
- надо коммитить/пушить/релизить;
- надо запускать Minecraft;
- надо трогать `server_pack/build.json` или `server_pack/manifest.json`;
- нужен продуктовый выбор.

Если агент не дал `NEXT ROUTE` или начал отвечать не по своей роли - это сбой дисциплины. Неси Штурману.

```text
Agent X сорвался с роли.
Что случилось:
- [кратко вставь, что он сделал не так]

Нужно:
- решить, куда это направить;
- дать короткий правильный prompt;
- при необходимости обновить правила агентов.
```

Модель: `normal`; если это связано с кодом, релизом, секретами или опасным действием - `strong`.

## После отчета Механика, Диспетчера или Упаковщика

Если агент пишет `Ready for Agent 1 review`, отправь отчет Ревизору.

```text
Прими handoff от [Agent X].
Проверь, можно ли перенести [TASK-ID] в Done или надо вернуть в работу.
Обнови tasks.md.
Назови один следующий task ID и кому его нести.
```

Модель: `normal`; если есть кодовый diff, провал тестов, release/installer/hashes - `strong`.

## После отчета Ревизора

Если Ревизор назвал следующий task ID, отправь задачу ответственному агенту:

- `L-*` -> Agent 2 / Механик.
- `P-*` -> Agent 3 / Диспетчер.
- `R-*` -> Agent 4 / Упаковщик.
- scope/confusion/new idea -> Agent 0 / Штурман.
- если Ревизор не дал `NEXT ROUTE` -> Agent 0 / Штурман.

Модель: `strong` для кода и релиза, `normal` для документов.

## После вредной или новой идеи

Отправь Штурману.

```text
Проверь идею на вред MVP/release.
Если это scope growth, отправь в Parking Lot.
Если нужно для релиза, пусть Ревизор сделает task ID.
```

Модель: `fast` или `normal`.

## Когда спрашивать пользователя

Только если надо выбрать то, что агент не должен решать сам:

- удалить/откатить чужие изменения;
- тронуть `server_pack/build.json` или `server_pack/manifest.json`;
- коммит/пуш/релиз;
- Minecraft launch;
- секреты, доступы, аккаунты;
- продуктовый разворот.
