MSLaunch / Codex restart kit

Зачем эта папка:
Текущий чат перегружен: тут смешались лаунчер, GitHub, хостинг, админка, дизайн, тянки, обновления и баги. Новые чаты нужны не чтобы учить проект с нуля, а чтобы дать каждому чату короткую роль и чистый контекст.

Рекомендованный минимум:
1. Координатор / аудит проекта
2. Лаунчер: стабильность, UI, баги, обновления
3. Панель / backend / сборки / репорты
4. Релиз / GitHub / хостинг / установщик
5. Mascot / анимации / ассеты

Если хочется меньше:
- минимум 3 чата: Координатор, Лаунчер, Панель+Релиз.
- mascot лучше держать отдельно, иначе он снова съест весь контекст.

Как запускать:
1. Открой новый чат Codex.
2. Вставь один из файлов PROMPT_*.txt целиком.
3. Если чат просит контекст, сначала дай ему 10_PROJECT_SNAPSHOT.txt.
4. Не кидай все промты в один чат.
5. Не вставляй пароли VPS, токены и личные секреты в README/репозитории.
